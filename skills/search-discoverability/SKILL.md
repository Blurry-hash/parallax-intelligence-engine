# Make a website discoverable through crawlability and useful search content

## Operational procedure

1. Separate deployment, crawlability, indexing and ranking. An AI-built page needs the same checks as any other site; submitting a sitemap does not guarantee indexing or ranking.
2. Inspect HTTP status, canonical URLs, robots directives, noindex, redirects, rendering accessibility, internal links and content uniqueness. Check both mobile rendering and server-delivered metadata.
3. Verify ownership in Search Console when authorized, submit a valid canonical XML sitemap and inspect representative URLs. Record actual indexing diagnostics, not assumptions from a successful deploy.
4. Map each page to a real user intent; write useful original content with descriptive titles/headings and relevant internal links. Metadata should describe the page accurately; keyword stuffing and repetitive generated pages are not quality improvements.
5. Test canonical/redirect behavior, sitemap coverage, missing pages and structured data only where relevant. Establish a baseline and monitor search impressions/clicks separately from conversions.

**Check:** A live page blocked by noindex remains undiscoverable despite a submitted sitemap. Explain the specific blocker and test the published response after changing it.
