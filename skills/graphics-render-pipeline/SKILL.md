# Efficient image/vector rendering

**Trigger:** Optimizing graphic assets and static image output.

## Operational procedure

1. Select correct format, resolution, color space and alpha handling before processing.
2. Use streaming or tiled transforms when large frames exceed memory budgets.
3. Inspect fidelity, ICC/color behavior, banding, dimensions and encoding speed.

**Check:** Rendered asset preserves intended details and meets target size.
