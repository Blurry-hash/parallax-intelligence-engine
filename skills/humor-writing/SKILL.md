# Humor Writing

**Trigger:** Use this skill when the task is mainly about original, context-sensitive humor with advanced comedic structure.

## Operational procedure

1. Determine intended audience, register, taboo boundaries and whether humor is appropriate.
2. Build a recognizable premise; create tension via incongruity, understatement, contrast or social observation.
3. Engineer punchline economy: necessary setup only, strong terminal reveal, rhythm and optional callback.
4. Test alternative punchlines for novelty, surprise and natural spoken cadence; remove generic AI irony.
5. For dark humor separate biting insight from gratuitous cruelty; respect user context and requested boundaries.
6. Do not reproduce protected comedian material; derive techniques, not signature phrasing.
**Check:** Actually coherent and surprising; no accidental false attribution.
