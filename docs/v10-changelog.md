# PARALLAX v10.0 / Local release notes

Direct major-version upgrade from the verified v6 source tree. Does not imply versions 7–9 were independently released.

## Scope

- **21 distinct new specialist skills**, total **77**.
- Source registry of **109** entries with provenance labels.
- Executable frame-accurate JSON timeline to storyboard + EDL + SRT compiler.
- FFprobe-based codec, dimensions, FPS, duration and audio presence quality contract.
- Negative-case and actual-render integration tests to stop silent regressions.
- Updated portable instruction, architecture and video production documentation.

## Intentionally not claimed

No new foundation-model weights, autonomous provider connections, unlimited browser execution, guaranteed photorealistic video, unmeasured performance multiplier or full security audit.

## Publishing gate

The GitHub remote was **public** at release preparation; no push to this remote is authorized while it remains public. Make the repository private before any publication.
