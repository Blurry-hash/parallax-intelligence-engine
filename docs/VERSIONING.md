# Version policy

`VERSION` is authoritative. Generation 2 begins at **2.0.0**, a deliberate numbering reset from the historical v11 series, not a return to its old code. Git commit IDs preserve the unambiguous lineage.

- Patch (`2.0.1`): compatible corrections and documentation.
- Minor (`2.1.0`): meaningful compatible capability with tests.
- Major (`3.0.0`): substantial coherent improvement or an incompatible contract, documented migration and representative evaluation. More files, inflated claims and cosmetic changes alone do not justify a new generation.

Release evidence must distinguish regression-test success from independently measured model benefit. Historical version labels remain in archived examples and continuity entries where they identify the original design.
