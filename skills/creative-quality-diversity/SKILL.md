# Creative mechanism diversity

**Trigger:** Use for tasks involving generate genuinely different solutions while balancing novelty, utility, cost and falsification.

## Operational procedure

1. Create a matrix of independent mechanism families rather than synonymous prompt variants.
2. Combine distant disciplines only when their causal assumptions are compatible.
3. Build a portfolio that includes robust baseline, unconventional feasible and high-upside experimental candidates.
4. Check prior art; originality claims require external comparison, not lexical similarity alone.
5. Choose a cheap falsification or prototype test for each proposed candidate.
6. Use blinded human evaluation for value and distinguish visual surprise from functional novelty.

**Check:** Evidence supports the outcome, protected constraints remain satisfied, limitations are explicit and executable checks were actually run. For unavailable capabilities, mark the step NOT EXECUTED.
